# Introduction

DomUI is a component-based Java framework for building AJAX web applications
without writing Javascript. This section describes what the framework is, what
it is good at, and what a developer can expect from it.

- [What is DomUI](what-is-domui/index.md) - the framework in a nutshell, and
  when to use it (or not).
- [Developer view of DomUI](developer-view-of-domui/index.md) - a quick list of
  facts: language, browsers, tools, layers and dependencies.

Once you know what it is, [Getting started](../getting-started/index.md) walks
you through your first application.
