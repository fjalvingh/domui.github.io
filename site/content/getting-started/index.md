# Getting started

The quickest way into DomUI is to run something. This section covers getting
DomUI itself building, and creating an application of your own from it.

- [Checking out DomUI and running the demo](running-the-demo/index.md) - build
  the framework and its demo application in Maven and IntelliJ.
- [Use the "example" skeleton for a new application](example-skeleton/index.md) -
  the encouraged way to start your own application.
- [Creating an application with the Maven archetype](maven-archetype/index.md) -
  a bare bones application from scratch.
- [Using the DomUI IntelliJ plugin](intellij-plugin/index.md) - editor support
  for DomUI pages and properties.
