# DomUI Github environment

The [master repository for DomUI is on Github](https://github.com/fjalvingh/domui). Pushes are automatically built [using TravisCI which can be found here](https://travis-ci.org/fjalvingh/domui).

If a build succeeds the resulting DomUI demo code will be deployed using DeployHQ.com, [which can be found here](https://domuiorg.deployhq.com/projects/domui/overview).
